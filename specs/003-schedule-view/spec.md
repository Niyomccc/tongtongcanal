# Feature: ดูตารางการแสดง (Schedule View)
Spec ID: SPEC-SCV-001 | Source: Use Case Specification UC-03 | Use case: UC-03
Owner: TBD | Status: Draft v2 | Updated: 2569-09-20

## Goal
นักศึกษา / ผู้ชม / วงดนตรี ดูรายชื่อวง ลำดับ วัน เวลา และสถานที่การแสดงของอีเว้นต์
เพื่อทราบกำหนดการแสดง โดยตารางตรงกับที่ผู้จัดงานเผยแพร่

## Scope
### In scope
- เลือกอีเว้นต์และดูตารางการแสดงที่เผยแพร่แล้ว
- เปิดหน้าตารางของอีเว้นต์ที่ยังไม่มีการเผยแพร่ตาราง และแจ้งว่ายังไม่มีตารางการแสดง
- แสดงรายชื่อวง ลำดับ วัน เวลา และสถานที่
### Out of scope
- จัดตารางการแสดง (UC-11) | ดูรายละเอียดอีเว้นต์ (UC-02)

## Constraints
- PRE-SCV-01 ผู้จัดงานได้จัดทำและเผยแพร่ตารางแล้วสำหรับกรณีที่ระบบต้องแสดงข้อมูลตาราง; หากยังไม่มีการเผยแพร่ ผู้ใช้ยังเปิดหน้าตารางได้และระบบต้องแจ้งว่ายังไม่มีตารางการแสดง (precondition สำหรับการแสดงข้อมูล)

## Requirements
- FR-SCV-01 ระบบต้องให้ผู้ใช้เลือกเมนูตารางการแสดงและเลือกอีเว้นต์                    <- UC-03 main flow ขั้น 1
- FR-SCV-02 ระบบต้องเรียกข้อมูลตารางการแสดงของอีเว้นต์ที่เลือก                       <- UC-03 main flow ขั้น 2
- FR-SCV-03 ระบบต้องแสดงรายชื่อวงตามลำดับการแสดง                                   <- UC-03 main flow ขั้น 3
- FR-SCV-04 ระบบต้องแสดงวัน เวลา และสถานที่ของแต่ละวง                              <- UC-03 main flow ขั้น 4
- FR-SCV-05 หากยังไม่มีการประกาศตาราง ระบบต้องแจ้งว่ายังไม่มีตารางการแสดง             <- UC-03 alternative flow
- FR-SCV-06 หากเรียกข้อมูลตารางจากฐานข้อมูลไม่ได้ ระบบต้องแจ้งผู้ใช้ว่าแสดงตารางไม่ได้   <- UC-03 exception flow

## Quality Requirements
- NFR-DAT-01 ข้อมูลตารางต้องถูกต้องและเป็นปัจจุบัน ตรงกับข้อมูลของผู้จัดงาน
- NFR-PERF-01 ระบบต้องรองรับผู้ใช้พร้อมกัน [N] คน โดยคำขอ [P]% ต้องตอบสนองภายใน [X] วินาที [ค่าจริงยังไม่กำหนด จึงยังทดสอบไม่ได้, Q-02]

## Acceptance Criteria
- [ ] AC-SCV-01 (FR-SCV-03)
      Given ผู้จัดงานเผยแพร่ตารางของอีเว้นต์แล้ว
      When  ผู้ใช้เปิดตารางการแสดง
      Then  แสดงรายชื่อวงครบถ้วนตามที่อยู่ในตาราง
- [ ] AC-SCV-02 (FR-SCV-04)
      Given ผู้จัดงานเผยแพร่ตารางของอีเว้นต์แล้ว
      When  ผู้ใช้เปิดตารางการแสดง
      Then  แสดงวัน เวลา และสถานที่ของแต่ละวง
- [ ] AC-SCV-03 (NFR-DAT-01)
      Given ผู้จัดงานบันทึกตารางการแสดงไว้
      When  ผู้ใช้เปิดตารางการแสดง
      Then  ตารางที่แสดงตรงกับข้อมูลของผู้จัดงาน
- [ ] AC-SCV-04 (FR-SCV-05)
      Given ยังไม่มีการประกาศตารางของอีเว้นต์
      When  ผู้ใช้เปิดตารางการแสดง
      Then  ระบบแจ้งว่ายังไม่มีตารางการแสดง
- [ ] AC-SCV-05 (FR-SCV-06)
      Given ระบบไม่สามารถเรียกข้อมูลตารางจากฐานข้อมูลได้
      When  ผู้ใช้เปิดตารางการแสดง
      Then  ระบบแจ้งผู้ใช้ว่าแสดงตารางไม่ได้

## Assumptions & Open Questions
- ASM-01 พฤติกรรมเมื่อเรียกข้อมูลจากฐานข้อมูลไม่ได้ (แจ้งข้อความให้ผู้ใช้ทราบ) เป็นข้อสันนิษฐานของผู้เขียน spec
- ASM-02 ผู้ใช้สามารถเปิดหน้าตารางได้แม้ผู้จัดงานยังไม่เผยแพร่ตาราง โดยระบบจะแจ้งว่ายังไม่มีตารางการแสดงและไม่แสดงข้อมูลตารางที่ยังไม่เผยแพร่
- ASM-03 ผู้ใช้ทุกคนดูตารางการแสดงได้โดยไม่ต้องเข้าสู่ระบบ เช่นเดียวกับการดูรายละเอียดอีเว้นต์ใน UC-02
- Q-02 ต้องกำหนดค่าจริงของ [X] วินาที, [P]% ของคำขอ และผู้ใช้พร้อมกัน [N] คนก่อนจึงจะทดสอบ NFR-PERF-01 ได้ (ผู้รับผิดชอบ: ทีมเอง)
- Q-03 ต้องใช้ AC ใดเพื่อยืนยันการเลือกเมนูตารางการแสดงและการเลือกอีเว้นต์? (ผู้รับผิดชอบ: ทีมเอง)
- Q-04 ลำดับการแสดงต้องใช้ลำดับที่ผู้จัดงานกำหนด หรือให้ระบบเรียงตามวันและเวลา? (ผู้รับผิดชอบ: ผู้จัดงาน / ทีมเอง)
- Q-05 วัน เวลา และสถานที่ของแต่ละวงต้องมีครบทุกค่าเสมอหรือไม่ และหากข้อมูลใดไม่มีต้องแสดงอย่างไร? (ผู้รับผิดชอบ: ผู้จัดงาน / ทีมเอง)
- Q-06 กรณีใดบ้างที่ถือว่าเรียกข้อมูลจากฐานข้อมูลไม่ได้ และระบบต้องแสดงข้อความหรือดำเนินการอย่างไร? (ผู้รับผิดชอบ: ทีมเอง)
