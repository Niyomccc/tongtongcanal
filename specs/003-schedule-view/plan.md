# แผนงาน: ดูตารางการแสดง (Schedule View)

## 1. สรุปแนวทาง

1. ผู้ใช้เปิดเมนูตารางการแสดงและเลือกอีเว้นต์ โดยไม่ต้องเข้าสู่ระบบ
2. ระบบเรียกข้อมูลตารางของอีเว้นต์ที่เลือก
3. หากตารางถูกเผยแพร่แล้ว ระบบแสดงรายชื่อวงตามลำดับ พร้อมวัน เวลา และสถานที่
4. หากยังไม่มีการเผยแพร่ตาราง ระบบแสดงข้อความว่ายังไม่มีตารางการแสดง และไม่แสดงข้อมูลที่ยังไม่เผยแพร่
5. หากเรียกข้อมูลจากฐานข้อมูลไม่ได้ ระบบแสดงข้อความว่าไม่สามารถแสดงตารางได้

## 2. เทคโนโลยีที่ใช้

| สิ่งที่เลือก | มาจาก | หมายเหตุ |
|---|---|---|
| ภาษา, framework, ฐานข้อมูล และรูปแบบ API | ทีมเลือกเอง ไม่ได้มาจาก spec | ต้องรองรับการเลือกอีเว้นต์ การเรียกข้อมูลตาราง และการแสดงสถานะสำเร็จ/ไม่มีข้อมูล/ผิดพลาด |

## 3. โมเดลข้อมูลเชิงตรรกะ

| Entity | ฟิลด์หลัก | รองรับ |
|---|---|---|
| Event | `event_id`, ข้อมูลอีเว้นต์ที่ใช้เลือก | FR-SCV-01 |
| Schedule | `schedule_id`, `event_id`, สถานะการเผยแพร่ | FR-SCV-02, FR-SCV-05, NFR-DAT-01 |
| ScheduleEntry | `schedule_id`, วง, ลำดับการแสดง, วัน, เวลา, สถานที่ | FR-SCV-03, FR-SCV-04, NFR-DAT-01 |

หมายเหตุ:
- ระบบต้องไม่ส่งหรือแสดง `Schedule` ที่ยังไม่เผยแพร่ตาม ASM-02
- วิธีตีความลำดับการแสดงและการจัดการฟิลด์วัน เวลา หรือสถานที่ที่ไม่มีค่า ต้องรอคำตอบ Q-04 และ Q-05
- ชื่อฟิลด์จริงและความสัมพันธ์กับข้อมูลวง/อีเว้นต์ให้ทีมกำหนดตามเทคโนโลยีที่เลือก

## 4. หน้าจอและการทำงานเชิงตรรกะ

| รายการ | การทำงาน | รองรับ |
|---|---|---|
| เมนูตารางการแสดง | เปิดหน้าสำหรับเลือกอีเว้นต์ | FR-SCV-01 |
| ตัวเลือกอีเว้นต์ | แสดงอีเว้นต์ที่ผู้ใช้เลือกดูตาราง | FR-SCV-01 |
| การเรียกตาราง | รับอีเว้นต์ที่เลือกและเรียกข้อมูลตาราง | FR-SCV-02 |
| ตารางที่เผยแพร่แล้ว | แสดงรายชื่อวงตามลำดับ วัน เวลา และสถานที่ | FR-SCV-03, FR-SCV-04 |
| สถานะยังไม่เผยแพร่ | แสดงข้อความว่ายังไม่มีตารางการแสดง และไม่แสดงรายการตาราง | FR-SCV-05, ASM-02 |
| สถานะเรียกข้อมูลล้มเหลว | แสดงข้อความว่าแสดงตารางไม่ได้ | FR-SCV-06, ASM-01 |

ข้อกำหนดเกี่ยวกับ AC สำหรับการเลือกเมนูและอีเว้นต์ยังรอคำตอบ Q-03 จึงยังไม่กำหนดชื่อ test หรือเงื่อนไขตรวจรับเพิ่มเติมแทนทีม

## 5. ตารางตรวจ Constraints และ Assumptions

| ID | ถูกนำไปใช้ที่ไหนใน plan | สถานะ |
|---|---|---|
| PRE-SCV-01 | แยกผลลัพธ์เป็นกรณีมีตารางเผยแพร่แล้วกับกรณียังไม่เผยแพร่ | ใช้แล้ว |
| ASM-01 | จัดการข้อผิดพลาดจากการเรียกข้อมูลและแสดงข้อความแก่ผู้ใช้ | ใช้แล้ว |
| ASM-02 | ไม่แสดงข้อมูลตารางก่อนเผยแพร่ แต่ยังเปิดหน้าตารางได้ | ใช้แล้ว |
| ASM-03 | ไม่บังคับ authentication สำหรับการดูตาราง | ใช้แล้ว |

## 6. แผนทดสอบจาก Acceptance Criteria

| AC ID | ชื่อ test | ทดสอบอย่างไร |
|---|---|---|
| AC-SCV-01 | `test_AC_SCV_01_show_bands_in_schedule_order` | เตรียมอีเว้นต์ที่เผยแพร่ตาราง แล้วตรวจว่ารายชื่อวงแสดงครบถ้วนตามลำดับในข้อมูลตาราง |
| AC-SCV-02 | `test_AC_SCV_02_show_date_time_and_venue` | เตรียมตารางที่มีข้อมูลของแต่ละวง แล้วตรวจวัน เวลา และสถานที่ที่แสดง |
| AC-SCV-03 | `test_AC_SCV_03_schedule_matches_published_data` | เปรียบเทียบข้อมูลที่ระบบแสดงกับข้อมูลตารางของผู้จัดงาน แล้วตรวจว่าตรงกัน |
| AC-SCV-04 | `test_AC_SCV_04_unpublished_schedule_message` | เตรียมอีเว้นต์ที่ยังไม่เผยแพร่ตาราง แล้วตรวจข้อความและตรวจว่าไม่มีรายการตารางถูกแสดง |
| AC-SCV-05 | `test_AC_SCV_05_schedule_load_failure_message` | จำลองการเรียกข้อมูลจากฐานข้อมูลล้มเหลว แล้วตรวจข้อความว่าแสดงตารางไม่ได้ |

ข้อจำกัดในการทดสอบ:
- AC-SCV-01 ถูกใช้ใน traceability ของ FR-SCV-01 ด้วย แต่ข้อความปัจจุบันตรวจเฉพาะการแสดงรายชื่อวง การทดสอบการเลือกเมนู/อีเว้นต์ต้องรอ Q-03
- การทดสอบลำดับและข้อมูลที่ไม่มีค่าต้องรอ Q-04 และ Q-05
- การทดสอบ NFR-PERF-01 ยังทำไม่ได้จนกว่าจะกำหนดค่า `[X]`, `[P]` และ `[N]` ตาม Q-02

## 7. ลำดับงาน

1. กำหนด flow ของหน้าเลือกอีเว้นต์และหน้าตาราง โดยคงการเข้าถึงแบบไม่ต้องเข้าสู่ระบบ (FR-SCV-01, ASM-03)
2. กำหนดโครงสร้างข้อมูลอีเว้นต์ ตาราง และรายการการแสดงให้เก็บข้อมูลตาม spec (FR-SCV-02, FR-SCV-03, FR-SCV-04, NFR-DAT-01)
3. สร้างการเรียกข้อมูลตารางของอีเว้นต์ที่เลือก และแยกผลลัพธ์เผยแพร่แล้ว/ยังไม่เผยแพร่ (FR-SCV-02, FR-SCV-05, ASM-02)
4. สร้างการแสดงผลรายชื่อวงตามลำดับ วัน เวลา และสถานที่ (FR-SCV-03, FR-SCV-04)
5. จัดการกรณีเรียกข้อมูลล้มเหลวและแสดงข้อความแก่ผู้ใช้ (FR-SCV-06, ASM-01)
6. เขียนและรันการทดสอบตาม AC-SCV-01 ถึง AC-SCV-05
7. เพิ่มการทดสอบ performance หลังทีมกำหนด `[X]`, `[P]` และ `[N]` แล้ว (NFR-PERF-01, Q-02)

## 8. สิ่งที่ยังไม่ทำ

- Q-02 ยังไม่มีค่าจริงของ `[X]`, `[P]` และ `[N]` จึงยังทดสอบ NFR-PERF-01 ไม่ได้
- Q-03 ยังไม่ระบุ AC สำหรับการเลือกเมนูตารางการแสดงและการเลือกอีเว้นต์ จึงยังไม่เพิ่มเงื่อนไขทดสอบแทนทีม
- Q-04 ยังไม่สรุปว่าจะใช้ลำดับที่ผู้จัดงานกำหนดหรือเรียงตามวันเวลา
- Q-05 ยังไม่สรุปว่าข้อมูลวัน เวลา และสถานที่ต้องครบหรือจัดการค่าที่ไม่มีอย่างไร
- Q-06 ยังไม่สรุปขอบเขตข้อผิดพลาดจากฐานข้อมูลและการตอบสนองที่ต้องการ
- ไม่รวมการจัดตารางการแสดง (UC-11) และการดูรายละเอียดอีเว้นต์ (UC-02) ตาม Out of scope
