# Feature: ยกเลิกการลงทะเบียน (Cancel Registration)
Spec ID: SPEC-CXL-001 | Source: Use Case Specification UC-05 | Use case: UC-05
Owner: TBD | Status: Draft v2 | Updated: 2569-09-20

## Goal
นักศึกษา / ผู้ชม ที่ไม่สามารถเข้าร่วมงานยกเลิกการลงทะเบียนของตนเองได้
โดยสถานะการลงทะเบียนเปลี่ยนเป็นยกเลิก และผู้จัดงานเห็นจำนวนผู้ลงทะเบียนที่เป็นปัจจุบัน

## Scope
### In scope
- เปิดดูข้อมูลการลงทะเบียนของตนเอง เลือกยกเลิก และยืนยัน
- เปลี่ยนสถานะเป็นยกเลิก และปรับปรุงจำนวนผู้ลงทะเบียน
### Out of scope
- ลงทะเบียนเข้าชมงาน (UC-04) | ตรวจสอบรายชื่อผู้เข้าร่วม (UC-13)

## Constraints
- PRE-CXL-01 ผู้ใช้มีสถานะลงทะเบียนเข้าร่วมงาน (precondition)

## Requirements
- FR-CXL-01 ระบบต้องให้ผู้ใช้เปิดข้อมูลการลงทะเบียนของตนเองและเลือกยกเลิกได้             <- UC-05 main flow ขั้น 1-2
- FR-CXL-02 ระบบต้องแสดงข้อความขอยืนยันก่อนยกเลิก                                  <- UC-05 main flow ขั้น 3
- FR-CXL-03 เมื่อผู้ใช้ยืนยัน ระบบต้องเปลี่ยนสถานะการลงทะเบียนเป็นยกเลิก
      และปรับปรุงจำนวนผู้ลงทะเบียนของอีเว้นต์ทันทีหลังยกเลิกสำเร็จ                    <- UC-05 main flow ขั้น 4-5
- FR-CXL-04 เมื่อผู้ใช้เลือกไม่ยืนยัน ระบบต้องคงข้อมูลการลงทะเบียนเดิมไว้               <- UC-05 alternative flow
- FR-CXL-05 เมื่อไม่พบข้อมูลการลงทะเบียน ระบบต้องแจ้งผู้ใช้ว่าไม่พบข้อมูล และไม่ดำเนินการยกเลิก <- UC-05 exception flow

## Quality Requirements
- NFR-DAT-01 ระบบต้องบันทึกข้อมูลการยกเลิกอย่างถูกต้อง

## Acceptance Criteria
- [ ] AC-CXL-01 (FR-CXL-02, FR-CXL-03)
      Given ผู้ใช้มีสถานะลงทะเบียนเข้าร่วมงาน
      When  เลือกยกเลิกและกดยืนยัน
      Then  ระบบยกเลิกการลงทะเบียนสำเร็จ
- [ ] AC-CXL-02 (FR-CXL-03, NFR-DAT-01)
      Given ผู้ใช้ยืนยันการยกเลิก
      When  ระบบยกเลิกสำเร็จ
      Then  สถานะการลงทะเบียนเปลี่ยนเป็น "ยกเลิก"
- [ ] AC-CXL-03 (FR-CXL-03)
      Given จำนวนผู้ลงทะเบียนของอีเว้นต์ก่อนยกเลิกเท่ากับ N
      When  ผู้ใช้ยกเลิกการลงทะเบียนสำเร็จ
      Then  จำนวนผู้ลงทะเบียนของอีเว้นต์ถูกปรับปรุงเป็น N-1
- [ ] AC-CXL-04 (FR-CXL-04)
      Given ระบบแสดงข้อความขอยืนยันการยกเลิก
      When  ผู้ใช้เลือกไม่ยืนยัน
      Then  ข้อมูลการลงทะเบียนเดิมคงอยู่ ไม่เปลี่ยนแปลง
- [ ] AC-CXL-05 (FR-CXL-05)
      Given ไม่พบข้อมูลการลงทะเบียนของผู้ใช้
      When  ผู้ใช้พยายามยกเลิก
      Then  ระบบแจ้งว่าไม่พบข้อมูล และไม่มีการเปลี่ยนแปลงข้อมูล

## Assumptions & Open Questions
- ASM-01 "ปรับปรุงจำนวนผู้ลงทะเบียน" หมายถึงจำนวนผู้ลงทะเบียนที่นับเฉพาะสถานะที่ยังไม่ยกเลิกลดลง 1 ต่อการยกเลิก 1 รายการ
- ASM-02 ปัจจุบันไม่มีเส้นตาย ผู้ใช้ยกเลิกได้ทุกเวลาที่สถานะการลงทะเบียนยังเป็น "ลงทะเบียน" หากผู้จัดงานกำหนดเส้นตายในอนาคต ให้ระบุเป็น "ก่อนวันงาน [N] วัน"
- ASM-03 เมื่อยกเลิกสำเร็จ จำนวนที่ว่างเพิ่มขึ้นทันที และผู้อื่นลงทะเบียนได้ทันที โดย UC-04 นับเฉพาะรายการที่ยังไม่ยกเลิก
- ASM-04 ผู้ใช้ที่ยกเลิกแล้วสามารถลงทะเบียนอีเว้นต์เดิมใหม่ได้ เพราะรายการเดิมมีสถานะ "ยกเลิก"
- Q-04 ระบบต้องยืนยันตัวตนและตรวจอย่างไรว่า registration ที่กำลังยกเลิกเป็นของผู้ใช้คนนั้น? (ต้องถามทีมเอง)
- Q-05 การเปลี่ยนสถานะและการปรับจำนวนผู้ลงทะเบียนต้องสำเร็จพร้อมกันทั้งคู่หรือไม่? (ต้องถามทีมเอง)
- Q-06 "ผู้จัดงานเห็นจำนวนผู้ลงทะเบียนที่เป็นปัจจุบัน" ต้องแสดงในฟีเจอร์นี้หรือเพียงปรับปรุงข้อมูลให้ฟีเจอร์อื่นนำไปแสดง? (ต้องถามผู้จัดงาน / ทีมเอง)
- Q-07 ข้อมูลใดบ้างที่ต้องบันทึกเมื่อยกเลิกการลงทะเบียน เช่น ผู้ยกเลิก เวลา อีเว้นต์ และสถานะก่อนยกเลิก? (ต้องถามทีมเอง)
- Q-08 หากไม่พบข้อมูลการลงทะเบียน ระบบต้องแสดงข้อความใด และ registration ที่ถูกยกเลิกไปแล้วถือเป็น "ไม่พบข้อมูล" หรือไม่? (ต้องถามทีมเอง)
