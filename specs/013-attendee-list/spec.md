# Feature: ตรวจสอบรายชื่อผู้เข้าร่วม (Attendee List)
Spec ID: SPEC-ATT-001 | Source: Use Case Specification UC-13 | Use case: UC-13
Owner: TBD | Status: Draft v2 | Updated: 2026-09-20

## Goal
ผู้จัดงานตรวจสอบรายชื่อและจำนวนผู้ลงทะเบียนของอีเว้นต์ที่ตนเป็นเจ้าของ/รับผิดชอบ โดยข้อมูลส่วนบุคคลของผู้ลงทะเบียนได้รับการปกป้องและมีการบันทึก log ทุกครั้งที่เข้าถึงข้อมูลที่จำเป็น

## Scope
### In scope
- เลือกอีเว้นต์ แสดงรายชื่อและจำนวนผู้ลงทะเบียน
- ค้นหาหรือกรองรายชื่อ
- จำกัดการดูข้อมูลเฉพาะผู้มีสิทธิ์
### Out of scope
- ลงทะเบียนเข้าชมงาน (UC-04) | ยกเลิกการลงทะเบียน (UC-05)

## Constraints
- PRE-ATT-01 มีข้อมูลการลงทะเบียนในระบบ (precondition)
- CON-ACC-01 เฉพาะผู้มีสิทธิ์เท่านั้นที่ดูข้อมูลได้

## Requirements
- FR-ATT-01 ระบบต้องให้ผู้จัดงานเลือกอีเว้นต์ที่ตนเป็นเจ้าของ/รับผิดชอบ และค้นหาข้อมูลผู้ลงทะเบียนของอีเว้นต์นั้น โดยสิทธิ์การเข้าถึงต้องผูกกับความสัมพันธ์ระหว่างผู้ใช้กับอีเว้นต์นั้น ๆ เท่านั้น <- UC-13 main flow ขั้น 1-2
- FR-ATT-02 ระบบต้องแสดงรายชื่อผู้ลงทะเบียนแบบข้อมูลขั้นต่ำที่จำเป็นเท่านั้น ได้แก่ ชื่อ-นามสกุล, สถานะการลงทะเบียน, วันที่ลงทะเบียน สำหรับอีเมลและเบอร์โทรถือเป็นข้อมูลส่วนบุคคล (PII) ที่ต้องจำกัดการแสดงผลเพิ่มเติม และแสดงได้เฉพาะเมื่อจำเป็นต่อการปฏิบัติงานจริง โดยมี access log ทุกครั้งที่เข้าถึงข้อมูล PII <- UC-13 main flow ขั้น 3
- FR-ATT-03 ระบบต้องแสดงจำนวนผู้ลงทะเบียนที่ยืนยันสำเร็จเท่านั้น (CONFIRMED) ไม่รวมผู้ที่ยกเลิก ถูกลบ หรือลงทะเบียนไม่สำเร็จ เช่น ค้างชำระเงินหรือฟอร์มไม่สมบูรณ์ <- UC-13 main flow ขั้น 4
- FR-ATT-04 ระบบต้องให้ผู้จัดงานค้นหาหรือกรองรายชื่อตามข้อมูลที่ต้องการได้ <- UC-13 alternative flow
- FR-ATT-05 หากไม่พบข้อมูลผู้ลงทะเบียน ระบบต้องแจ้งผู้จัดงานว่าไม่พบข้อมูล <- UC-13 exception flow
- FR-ATT-06 ระบบต้องอนุญาตให้เฉพาะผู้มีสิทธิ์ที่เกี่ยวข้องกับอีเว้นต์นั้นเท่านั้น ดูรายชื่อและข้อมูลผู้ลงทะเบียน <- UC-13 NFR

## Quality Requirements
- NFR-SEC-01 ข้อมูลส่วนบุคคลของผู้ลงทะเบียนต้องได้รับการปกป้อง: ใช้หลัก minimum necessary, จำกัดการแสดงผลที่จำเป็นจริงเท่านั้น และบันทึก access log ทุกครั้งที่มีการเข้าถึงข้อมูล PII
- NFR-ACC-01 เฉพาะผู้มีสิทธิ์ที่เกี่ยวข้องกับอีเว้นต์เท่านั้นที่ดูข้อมูลได้
- NFR-DAT-01 รายชื่อและจำนวนที่แสดงต้องตรงกับฐานข้อมูล และจำนวนผู้ลงทะเบียนต้องนับเฉพาะสถานะยืนยันสำเร็จเท่านั้น

## Acceptance Criteria
- [ ] AC-ATT-01 (FR-ATT-01, FR-ATT-02)
      Given ผู้จัดงานเป็นเจ้าของ/รับผิดชอบอีเว้นต์นั้น
      When  ผู้จัดงานเลือกอีเว้นต์
      Then  ระบบแสดงรายชื่อผู้ลงทะเบียนของอีเว้นต์นั้นเท่านั้น
- [ ] AC-ATT-02 (FR-ATT-03)
      Given อีเว้นต์มีผู้ลงทะเบียนที่สถานะยืนยันสำเร็จ
      When  ผู้จัดงานเลือกอีเว้นต์
      Then  ระบบแสดงจำนวนผู้ลงทะเบียนที่ยืนยันสำเร็จเท่านั้น และไม่รวมผู้ที่ยกเลิก ถูกลบ หรือไม่สำเร็จ
- [ ] AC-ATT-03 (NFR-DAT-01)
      Given มีข้อมูลผู้ลงทะเบียนอยู่ในฐานข้อมูล
      When  ผู้จัดงานเปิดรายชื่อผู้เข้าร่วม
      Then  รายชื่อและจำนวนที่แสดงตรงกับข้อมูลในฐานข้อมูล และจำนวนคำนวณจากสถานะยืนยันสำเร็จเท่านั้น
- [ ] AC-ATT-04 (FR-ATT-04)
      Given ผู้จัดงานเปิดรายชื่อผู้เข้าร่วมแล้ว
      When  ค้นหาหรือกรองรายชื่อ
      Then  แสดงเฉพาะรายชื่อที่ตรงกับเงื่อนไข
- [ ] AC-ATT-05 (FR-ATT-05)
      Given อีเว้นต์ไม่มีข้อมูลผู้ลงทะเบียน
      When  ผู้จัดงานเปิดรายชื่อผู้เข้าร่วม
      Then  ระบบแจ้งว่าไม่พบข้อมูลผู้ลงทะเบียน
- [ ] AC-ATT-06 (FR-ATT-06, NFR-ACC-01, NFR-SEC-01)
      Given ผู้ใช้ไม่มีสิทธิ์ที่เกี่ยวข้องกับอีเว้นต์นั้น หรือไม่มีสิทธิ์เข้าถึงข้อมูล PII
      When  พยายามเปิดรายชื่อผู้เข้าร่วมหรือเข้าถึงข้อมูล PII
      Then  ระบบไม่อนุญาต ไม่แสดงข้อมูลส่วนบุคคล และบันทึก access log

## Assumptions & Open Questions
- ASM-01 พฤติกรรมเมื่อไม่พบข้อมูล (แจ้งข้อความให้ผู้จัดงานทราบ) เป็นข้อสันนิษฐานของผู้เขียน spec
- ASM-02 จำนวนผู้ลงทะเบียนคำนวณจากสถานะ "ยืนยันสำเร็จ" เท่านั้น ไม่รวมผู้ที่ยกเลิก ถูกลบ หรือไม่สำเร็จ เช่น ค้างชำระเงินหรือฟอร์มไม่สมบูรณ์
- ASM-03 ผู้จัดงานสามารถดูรายชื่อผู้ลงทะเบียนได้เฉพาะอีเว้นต์ที่ตนเป็นเจ้าของ/รับผิดชอบ และสิทธิ์การเข้าถึงต้องผูกกับความสัมพันธ์ระหว่างผู้ใช้กับอีเว้นต์นั้น ๆ
- ASM-04 รายชื่อต้องแสดงข้อมูลขั้นต่ำเป็น ชื่อ-นามสกุล, สถานะการลงทะเบียน, วันที่ลงทะเบียน; อีเมลและเบอร์โทรเป็น PII ที่ต้องจำกัดการแสดงผลและมี access log ทุกครั้งที่เข้าถึง
- Open Questions: ไม่มี
