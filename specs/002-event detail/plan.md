# Technical Plan: ดูรายละเอียดอีเว้นต์

## ขอบเขต
รองรับการเลือกอีเว้นต์และแสดงชื่องาน วันที่ เวลา สถานที่ และรายละเอียดกิจกรรม
ตาม FR-EVD-01 และ FR-EVD-02 รวมถึงการแสดงข้อมูลล่าสุดและกรณีไม่พบข้อมูล

## แนวทางดำเนินงาน
1. รับอีเว้นต์ที่ผู้ใช้เลือกจากหน้าอีเว้นต์ (FR-EVD-01)
2. ค้นหาข้อมูลอีเว้นต์ตามรายการที่เลือก (FR-EVD-02)
3. แสดงชื่อและรายละเอียดกิจกรรม (AC-EVD-01)
4. แสดงวัน เวลา และสถานที่ (AC-EVD-02)
5. ใช้ข้อมูลอีเว้นต์ล่าสุดเมื่อเปิดดูรายละเอียด (FR-EVD-03)
6. แจ้งผู้ใช้เมื่อไม่พบข้อมูลอีเว้นต์ (FR-EVD-04)

## การทดสอบ
- ทดสอบการเลือกอีเว้นต์และการแสดงข้อมูลตาม AC-EVD-01
- ทดสอบการแสดงวัน เวลา และสถานที่ตาม AC-EVD-02
- ทดสอบการแสดงข้อมูลล่าสุดตาม AC-EVD-03
- ทดสอบกรณีไม่พบข้อมูลตาม AC-EVD-04
- ทดสอบความถูกต้องของข้อมูลตาม NFR-DAT-01 โดยอ้างอิง AC-EVD-03

## NFR-PERF-01
รอกำหนดค่า (Q-02) จึงยังจัดทำการทดสอบเชิงประสิทธิภาพไม่ได้

## ข้อจำกัด
- ต้องมีข้อมูลอีเว้นต์ในระบบก่อนดำเนินการ (PRE-EVD-01)
- ไม่รวมการสร้างหรือแก้ไขอีเว้นต์ (UC-10)
- ไม่รวมการลงทะเบียนเข้าชมงาน (UC-04)
- ไม่รวมการดูตารางการแสดง (UC-03)
- เทคโนโลยีที่ใช้: ทีมเลือกเอง ไม่ได้มาจาก spec
