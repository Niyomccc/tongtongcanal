# Feature: ดูรายละเอียดอีเว้นต์ (Event Detail)
Spec ID: SPEC-EVD-001 | Source: Use Case Specification UC-02 | Use case: UC-02
Owner: TBD | Status: Draft v1 | Updated: 2569-09-20

## Goal
นักศึกษา / ผู้ชม / วงดนตรี เลือกอีเว้นต์แล้วดูรายละเอียด (ชื่องาน วันที่ เวลา สถานที่ และรายละเอียดกิจกรรม)
ที่เป็นข้อมูลล่าสุดได้ เพื่อให้ผู้จัดงานเผยแพร่ข้อมูลงานถึงผู้ใช้

## Scope
### In scope
- เลือกอีเว้นต์จากหน้าอีเว้นต์
- แสดงรายละเอียดอีเว้นต์ และแสดงข้อมูลล่าสุดเมื่อมีการแก้ไข
### Out of scope
- สร้าง / แก้ไขอีเว้นต์ (UC-10) | ลงทะเบียนเข้าชมงาน (UC-04) | ดูตารางการแสดง (UC-03)

## Constraints
- PRE-EVD-01 มีข้อมูลอีเว้นต์อยู่ในระบบ (precondition)

## Requirements
- FR-EVD-01 ระบบต้องให้ผู้ใช้เลือกอีเว้นต์จากหน้าอีเว้นต์ได้                          <- UC-02 main flow ขั้น 1-2
- FR-EVD-02 ระบบต้องค้นหาข้อมูลของอีเว้นต์ที่เลือก และแสดงรายละเอียด
  ได้แก่ ชื่องาน วันที่ เวลา สถานที่ และรายละเอียดกิจกรรม                            <- UC-02 main flow ขั้น 3-4
- FR-EVD-03 เมื่อข้อมูลอีเว้นต์ถูกแก้ไข ระบบต้องแสดงข้อมูลล่าสุด                      <- UC-02 alternative flow
- FR-EVD-04 เมื่อไม่พบข้อมูลอีเว้นต์ ระบบต้องแจ้งผู้ใช้ว่าไม่พบข้อมูล                   <- UC-02 exception flow

## Quality Requirements
- NFR-DAT-01 ข้อมูลที่แสดงต้องถูกต้องตรงกับข้อมูลที่ผู้จัดงานบันทึกไว้
- NFR-PERF-01 ระบบต้องตอบสนองรวดเร็ว [ค่าที่วัดได้: ต้องกำหนด, Q-02]

## Acceptance Criteria
- [ ] AC-EVD-01 (FR-EVD-02)
      Given มีอีเว้นต์อยู่ในระบบ
      When  ผู้ใช้เลือกอีเว้นต์
      Then  แสดงชื่อและรายละเอียดกิจกรรมของงาน
- [ ] AC-EVD-02 (FR-EVD-02)
      Given มีอีเว้นต์อยู่ในระบบ
      When  ผู้ใช้เลือกอีเว้นต์
      Then  แสดงวัน เวลา และสถานที่ของงาน
- [ ] AC-EVD-03 (FR-EVD-03, NFR-DAT-01)
      Given ผู้จัดงานแก้ไขข้อมูลอีเว้นต์แล้ว
      When  ผู้ใช้เปิดดูรายละเอียดอีเว้นต์นั้น
      Then  ข้อมูลที่แสดงเป็นข้อมูลล่าสุด
- [ ] AC-EVD-04 (FR-EVD-04)
      Given ไม่พบข้อมูลอีเว้นต์ที่ผู้ใช้เลือก
      When  ผู้ใช้เปิดดูรายละเอียด
      Then  ระบบแจ้งว่าไม่พบข้อมูลอีเว้นต์
